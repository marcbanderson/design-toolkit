design-toolkit / overlay, prototype

Select something on the screen and change it, but only to a token

The panel on the right reads the selected element's gap, padding, margin and text as tokens, flags what is off the ladder, and offers only the ladder to change it to. Changes preview live and accumulate. Export turns them into the prompt that asks Claude Code to make the edits in the codebase and mirror them to Figma.

Try it

  1. Click the three stat tiles. The grid gap is 10, so the panel flags it and offers the nearest token.
  2. Click the insight block. The button sits 8 under its text; the judgment lint asks for a full unit.
  3. Click the second paragraph. It is 15/22, which matches nothing on the ramp.
  4. Make a few changes, then press Export prompt.

What is seeded wrong

  1. .stats gap 10, off ladder
  2. .stat padding 14, off ladder
  3. .insight button at 1/3 u from its text
  4. .copy paragraphs at 12, a middle rung in the reading flow
  5. .copy p.off text at 15/22, off ramp

Use it on your own build

In the project, run ~/.claude/tools/overlay-server. It reads the contract, serves the script and prints one include line for the dev build. The panel then holds the contract's ladder and ramp, and Export gains Send to session, which writes the prompt to .toolkit/inbox/ for the session to apply. Without the server the script still works from a manifest or by inference, and Export copies the prompt instead.

Alt+Shift+D hides and shows the panel. Escape clears the selection.
